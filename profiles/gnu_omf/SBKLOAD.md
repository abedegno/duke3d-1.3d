# Finite SBKLOAD source subset

This profile extension uses the existing unmodified GNU2.44 assembler and
objconv2.57 normal home, and the normal pinned Capstone decoder. No new tool,
converter patch, parser or generic runtime comparison rule is introduced.

The authored symbolic implementation owns all4884CODE+520DATA bytes and149
relocations, with15 true public routines/markers and8 genuine imports. Real
private COFF labels and signed ABS frame/field/selector constants are retained
as qualified nonexported receipt identities, not emitted LPUB aliases. Original
EasyOMF local definitions are genuinely empty. Source `.equ` is a compile-time
expression; signed values map modulo2**32 to COFF's unsigned field representation.

Real source grammar adds comma-separated `.globl`/`.extern` declarations to the
closed NRPN audit, without publishing private labels. All171 local source names,
90ABS constants, backing/uses,34CODE pointer fields, one CS dispatch and all149
translated fields must remain covered. Direct relocations to nonzero public
values are still rejected; the ordinary assembler resolves same-section public
calls. The independent own selfcall fixture is historical characterization,
never a normal build dependency.

Source/control-flow/stack semantics are explicit assembly, not recovered C
identity. Actual opcode encodings arise only from ordinary named instructions,
documented GNU direction/branch spellings and real ALIGN4. The two256-byte WORD
threshold arrays are emitted from the inferred rational EMU envelope model;
no observed target array is a producer input. Full original/LE checks follow
source production and remain mandatory.

Five standard output sections and FLAT group differ from the original two-segment
Easy module/DGROUP. Empty default sections are preserved. Exact output inventories
and encoded typed fields are pinned, and full verification resolves genuine
addresses rather than nominally renaming groups. This is not general COFF support.
