# Finite complete ZONE subset

The unchanged common profile pins the already reviewed GNU2.44/objconv assets
and historical hardware provenance. zone-subset.json supplies ZONE's separate
closed grammar/authorization; other module guards and default generic semantics
are unchanged. Actual assembler additions -L/-no-pad-sections preserve real
L-prefix identities and exact odd extents; they are measured producer choices,
not an optimization search. Explicit checked Capstone homes audit operands.

The source has eight exact sections: three empty native defaults, CODE2367,
CONST1427, empty CONST2, initialized DATA32 and unbacked BSS48. Custom source
sections are genuinely BYTE-aligned; actual original target alignment16/4/4/16
is checked, not pretended to be the source's raw alignment. Empty unreferenced
CONST2 has no primary COFF section symbol; all seven actual structural schemas
and every file/private/public/import/ABS identity are checked exactly.

Full source/listing/native byte and typed field checks, all127C_STAT identities,
all17ABS identities and complete114-role/seven-private correspondence are
mandatory. No private export, fabricated LPUB, target byte input, converter/
object/instruction patch, field mask or general COFF support is authorized.
